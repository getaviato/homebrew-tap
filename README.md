# Aviato Homebrew tap

```bash
brew install getaviato/tap/aviato
```

Installs `aviato`, the [Aviato](https://getaviato.com) CLI and connector. Casks here are published automatically by each release of [getaviato/connector](https://github.com/getaviato/connector); do not edit them by hand.

Documentation: [docs.getaviato.com](https://docs.getaviato.com/integrations/connector).
